1. The situation in one paragraph

We're a team of 4 at the European Defence Tech Hackathon (EDTH) Paris, 20–22 Nov 2026. Pitches are Sunday evening for preselected teams. We're building "Siesta", an edge sensor node that listens for drones (Challenge 9), looks with a camera detector and tracker only when needed (Challenge 6), and sends only the most valuable frames over a weak link (Challenge 8). All three run on the Axelera Embedded 110m (Metis AIPU, 1 GB), which is available on site. Tagline: "Eyes closed, ears open. We nap so you don't have to." As of Sat 12:05 the code kit is written and passes 15/15 tests on the real kit data, and real model training is starting on the team's M4 Max MacBook. No real accuracy numbers exist yet.

6. Key kit facts (full list in docs/2_TEAM_BRIEF_plan_roles_checkpoints.md Section 2) [verified]

Ch 6 - Classes 0 drone_air, 1 airplane, 2 helicopter. - Train 859 (14 clips) / valid 422 / test 328; 200 calibration images. - 8 tracking sequences: valid seq 1–4 with GT, test seq 5–8. - COCO category_id is 0-based; MOT class_id and frame are 1-based; top 100 per image. - MOT matching is IoU ≥ 0.5, class-agnostic. - ONNX outputs must be read by name (dets, labels). - The baseline runs CPU ONNX Runtime at 40 ms/frame; no trained weights are shipped. - The backbone-only export (features [1,256,24,24]) is the Metis starting point. - Proposed judging: Detection 40 / Tracking 40 / Edge 20.

Ch 8 - 947 frames / 282 clips; train 698 / valid 138 / test 111. - Test budgets k = 1 (1%) and 6 (5%); ties broken pessimistically. - JSONL {"id", "triage_keep", "priority_score"}. - Proposed judging: capture 55 / Spearman 25 / Metis 20 (bonus for clip dedup and 100% on-chip).

Ch 9 - 62 clips; train 48 / valid 8 / test 6. - JSONL {"id", "wake_triggered", "sound_class"}. - The trainer stores the wake threshold inside the ONNX. - Proposed judging: wake F1 40 / accuracy 25 / camera-off 20 / Metis 15.

Metis compile [verified, Axelera docs] - axcompile -i model.onnx --imageset <calib> --transform preprocess.py --input-shape 1,3,H,W -o out/. - --transform loads get_preprocess_transform(image), which takes a PIL image or array and returns a torch.Tensor. - Output: compiled_model/ + compilation_report.json (with a status field). - The CNNs have normalisation inside the graph; RF-DETR needs ImageNet normalisation.

12. Glossary

  • MOTA: 1 − (misses + false positives + ID switches) / ground-truth boxes.
  • IDF1: how consistently each object keeps one ID.
  • Continuity: share of ground-truth frames covered.
  • small_AP: AP on boxes < 32×32 px.
  • Capture@k%: high-priority frames among the top k% (budget-normalised).
  • MPS: Apple GPU backend.
  • Metis / Embedded 110m: Axelera's AI chip on an M.2 card, 1 GB.
  • Voyager SDK / axcompile: Axelera's toolchain.
  • INT8 calibration: setting quantisation ranges using sample images.
  • Host tail: the code that runs on the host CPU after the chip (decoder, tracker).
  • LOO / leave-one-sequence-out: tune on 3 sequences, test on the 4th, rotate.
